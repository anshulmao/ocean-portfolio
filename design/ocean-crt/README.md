# CRT expedition design

The two imagegen boards were generated before runtime implementation using Anshul's map and phosphor-monitor references.

- `phosphor-dive-board.png`: heading tape, angled left chart, compact instruments and a sun/moon time scrubber.
- `field-archive-board.png`: archival profile, project and resume presentation.
- `PROMPTS.md`: exact generation prompts; built-in imagegen was used.
- `DEPLOYMENT.md`: protected-preview-first static hosting plan.

Use the boards for visual direction, not factual content. Their invented coordinates, dates, addresses and project artwork are illustrative. The runtime preserves existing verified portfolio copy and images, uses the actual reef height function for bathymetry, and retains the astronomical Kuala Lumpur sky.

The CRT effect is confined to interface panels: near-black casing, lime phosphor, fine scanlines, restrained glow, square framing and monospace reading. Keep the ocean naturally colored. No flicker or full-screen pixel noise; reduced-motion remains supported.
