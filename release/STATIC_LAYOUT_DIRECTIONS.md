# Static portfolio layout directions

Open `directions.html` in the generated build to compare five complete options. Each page includes a switcher for the other directions.

| Direction | Page | Layout and navigation |
| --- | --- | --- |
| Portrait first | `direction-01.html` | A large portrait and introduction. Top navigation for profile, work, approach, experience, and résumé. |
| Work first | `direction-02.html` | A compact introduction and wide case-study rows. Top navigation emphasizes work and track record. |
| Field guide | `direction-03.html` | A portrait and persistent side navigation on desktop. The navigation becomes a horizontal strip on phones. |
| Chapters | `direction-04.html` | Numbered chapter navigation. The page presents the method before the work. |
| Compact overview | `direction-05.html` | A compact project grid, career summary, and fixed navigation dock. |

All options retain the shared ocean palette, glass surfaces, source copy, project pages, and résumé downloads. Preview pages have `noindex` metadata and do not enter the sitemap.

The main `profile.html` also moves the photo section before the projects and removes the empty left offset from Experience and Résumé.
