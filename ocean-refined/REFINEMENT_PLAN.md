# Ocean refinement

The original ocean is preserved. This working copy is `ocean-refined`.
Checkpoint: `portfolio/checkpoints/ocean-before-refinement-20261011-023326.zip`.

## Direction
- Calm, coherent marine life: remove the large procedural visitors and jittery imported fish; replace schooling fish with shaped bodies, fins and smooth group avoidance.
- First-person exploration by default. Dive approaches the swimmer before entering the view. V changes to an attached third-person camera. Escape releases the pointer.
- Atlas journeys work immediately; deep return journeys show the swimmer ascending from a side view.
- Smooth reef shelves and drop-offs, dense coral habitats with detailed fans, barrels and massive coral. Retain safe landmark approaches and cave exits.
- Correct the doubled horizon reflection and add distant gliding seabirds.
- Reuse coral geometry and textures, avoid expensive animated model assemblies, retain reduced-motion and lower-detail modes.

## Acceptance
Verify surface/dive/first-person/third-person/atlas/ascent, pointer release and recapture, mobile layout, model loading, console errors and scene draw counts. Review actual rendered surface and underwater views. Software-rendered timings are diagnostic only, not a claim of device performance.
